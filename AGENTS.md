# Agent Guidance

## Repository Structure

- **Monorepo**: `backend/` (NestJS) and `frontend/` (React/Vite)
- Root `package.json` contains TypeSpec/OpenAPI codegen tools (`openapi-typescript`, `@typespec/*`)

## Key Commands

**Backend** (from `backend/`):
- `npm run build` — NestJS compile to `dist/`
- `npm run start:dev` — watch mode

**Frontend** (from `frontend/`):
- `npm run dev` — Vite dev server (port 5173)
- `npm run build` — `tsc && vite build`

## Critical: CORS Port Lock

Backend CORS is hardcoded to `http://localhost:5173` (see `backend/src/main.ts:9`). Vite dev server must run on its default port 5173 — do not change it.

## CI / Workflow

`.github/workflows/hexlet-check.yml` is auto-generated by the Hexlet platform. **Do not edit it.**

## TypeScript

- Backend uses `commonjs` module, `ES2021` target
- Frontend uses `ESNext` module, `ES2020` target, `bundler` module resolution
- Both have `strictNullChecks` / `strict` enabled

## Tailwind CSS v4

Frontend uses Tailwind v4 with `@tailwindcss/postcss` plugin (not the old `tailwind.config.js` approach — though config still exists for compatibility, the PostCSS plugin is the actual pipeline).
